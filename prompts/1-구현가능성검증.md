1. 요구사항
  - 온보딩(필수) : 응원팀 선택 (팀명 + 대표색상으로 목록이 나오고 선택하는 방식)
  - 핵심 작동흐름 : 앱 실행
    → 오늘야구각 로고 표시
    → 응원 팀 선택
    → 오늘 경기 화면 진입
    → 꿀잼지수가 가장 높은 오늘의 추천 경기가 최상단에 표시
    → 아래는 다른 경기, 경기시간, 꿀잼지수 표시
    → 사용자가 경기 카드 선택
    → 경기 상세 화면 진입
    → 꿀잼지수, 한 줄 예측, 관전 포인트 확인
  - 오늘 경기 탭 : 오늘 열리는 KBO 경기 정보를 확인할 수 있다.
  - 내팀 탭 : 사용자가 선택한 응원 팀 중심으로 정보를 보여준다.
  - 설정 탭 : 최소한의 설정만 제공한다.
  - 꿀잼지수는 오늘야구각의 핵심 기능이다.
    각 경기를 0점부터 100점까지 점수화한다.
    초기 버전에서는 AI가 아니라 간단한 규칙 기반 계산 방식을 사용한다.

2. 구현 디테일
  - 안드로이드/IOS 앱으로 만들거다.
  - 기술은 적절히 너가 추천해줘야함
  - 최대한 구현이 쉬운 기술을 사용한다. 에러가 적게 생기고, 빨리 완성할 수 있어야한다.
  - 도트 UI는 이미지보다 CSS 스타일과 아이콘 중심으로 구현한다.
  - KBO 경기 정보 관련 실데이터 API에 대해 확인 필요

3. 제약조건
  - 서버를 사용하지 않는다.
  - 로그인을 구현하지 않는다.

4. 완료 기준
  - 핵심 작동 흐름이 정상 작동한다.
  - 온보딩에서 응원 팀을 선택할 수 있다.
  - 오늘 경기 탭에서 오늘의 추천 경기가 표시된다.
  - 경기 상세 화면이 정상 작동한다.
  - 내 팀탭이 정상 작동한다.
  - 도트 UI가 전체 화면에 적용된다.
