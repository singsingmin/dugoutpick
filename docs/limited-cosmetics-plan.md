# 한정 꾸미기 상품 운영 계획 (야구공 장기 sink)

> 목적: 야구공(꾸미기 전용 재화)의 **장기 소비처**를 유지. 배경/스킨을 다 사버린 고인물에게도 살 것을 계속 공급.
> 근거: [roadmap.md §G-P4](roadmap.md) · 보상 시스템 확장 설계(2026-07-09 확정).
> 인프라: **한정 판매 윈도우(마이그레이션 0020)** — `backgrounds.available_from/until` + `purchase_background` 게이트. 한정 오픈/마감을 **SQL만으로** 제어(코드 배포 불필요).

## 운영 원칙

- **케이던스**: 엄격한 매월보다 **KBO 시즌 이벤트 연동 번들 드롭**. 시즌 중 2~3회면 sink로 충분, 매월 1종은 상한 목표.
- **가격**: 상시 배경 40~60 / 한정 80~200 / 프리미엄 최고가 200. (상시 40~60은 별도 유지 — 신규 유저용)
- **명예형과 구분**: 월간 챔피언 룸·시즌 트로피룸은 랭킹 보상 전용(구매 불가). 한정 상품은 **구매형**(currency).
- **아트 전제**: 각 상품은 **아트 에셋이 먼저** 있어야 시드 가능(없으면 상점에 깨진 이미지). 순서 = 기획 확정 → 아트 제작(8비트 톤 일관성, 배경 941×1672) → 시드+config → 윈도우 UPDATE.
- **날짜**: 아래 판매기간은 잠정. KBO 확정 일정·명절(설·추석)·포스트시즌 대진 확정 후 조정.
- **연도**: id의 연도 접미사는 매년 교체(라인업은 연간 반복 템플릿).

## 상품 추가 절차 (아트 준비 후)

1. **아트 제작**: 8비트 레트로 톤, 배경 941×1672(stadium-bg 규격). 마젠타→크로마키→webp 파이프라인(scripts) 활용.
2. **에셋 배치 + config**: `app/assets/…webp` + `app/utils/lockerBackgroundConfig.ts`(배경) 또는 스킨 config 1줄.
3. **서버 시드**: `backgrounds` 테이블에 `(id, price, unlock_type='currency')` insert.
4. **윈도우 오픈**(코드 배포 불필요):
   ```sql
   update public.backgrounds
     set available_from  = '2026-07-15 00:00+09',
         available_until = '2026-08-02 23:59+09'
     where id = 'lockerbg.allstar_2026';
   ```
   - 상시 상품은 두 값 null.
   - `available_from`만/`available_until`만 설정도 가능.
5. **마감**: 기간 지나면 `purchase_background`가 자동으로 `not_available` 반환(클라 토스트).

## 향후 과제 (첫 드롭 시 함께)

- 한정 상품의 **클라 뱃지·"D-일" 기간 표시**: 지금은 미판매라 미구현. 첫 드롭 때 실제 상품과 함께 붙임(availability를 클라가 조회하도록 RPC/뷰 노출 필요).
- 한정 상품 **재판매 정책**(다음 해 같은 시즌에 재오픈 vs 영구 한정) 결정.
