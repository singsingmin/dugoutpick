# 예측 리그 설계 (Prediction League) — 오늘야구각

> **성격:** 개발자 의사결정 문서. 정책·데이터·UX·무결성 중심. "베팅"으로 오해될 표현 금지.
> **상태:** 설계 확정(2026-07-05 논의). **구현 미착수** — 2026 시즌 데이터 수집·폴리싱 중, 출시 목표 2027 초.
> **착수 선행:** Phase 3(계정/DB) 완료 ✅ · **Phase 3-Pre(판정 파이프라인) 필요** · 예측 중복방지 · 마감 잠금 · 보상 지급 기록.
> **관련:** [roadmap.md](roadmap.md) E Phase 3-Pre/4/5 · [phase3-account-design.md](phase3-account-design.md) · [adr.md](adr.md).
> **표기:** 구현 확정 아닌 항목은 "(후속 검토)". MVP / 후속 / 금지 분리.

---

## 0. 목표 · 성격

- **하루 1회 무료 예측** — "오늘 제일 재밌을 경기 1개"를 고른다.
- **비베팅.** 야구공을 걸거나 소모하지 않는다. 배당·판돈·베팅·수익률 표현 사용 금지 → **"예측 참여 · 적중 보상 · 랭킹 포인트"**.
- **판정 = 서버가 경기 종료 후 실제 경기 데이터**(recapScore / liveHeat / 경기 이벤트) 기반으로 산출. **꿀잼지수는 힌트이고 정답이 아니다.**
- **타깃 = 찐팬(헤비 팬) 위주 opt-in.** 후크 = 내 안목 증명 + 소소한 경쟁 + 수집.
- 핵심 기능(꿀잼지수)을 가리지 않는 **게임층**. 리더보드는 있되 과하게 앞세우지 않는다.

## 1. 핵심 결정사항 요약

| 항목 | 결정 |
|---|---|
| 참여 | 하루 1회 무료, "오늘 제일 재밌을 경기 1개" |
| 마감 | **그날 첫 경기 시작 전까지** (이후 신규·변경 모두 불가) |
| 판정 | 서버, 실제 경기 데이터. `actualTopGameId` + 동률 시 `tiedGameIds` |
| 점수 | **포인트**(적중·연속 주축, 참여 소량) |
| 메인 랭킹 | **월간 포인트 랭킹 1개** |
| 보조 랭킹 | 월간 적중률 랭킹(최소 참여 조건) |
| 연속 적중 | 별도 랭킹 X → 내 기록·프로필 요약·업적/칭호 조건 |
| 보상 | 3층(참여·적중 / 월간 / 시즌) |
| 시즌 보상 | 한정 칭호·전용 스킨·라커룸 배경 = 야구공으로 못 삼(프레스티지) |
| 야구공 | 꾸미기·표현·수집만 (편의/기능 해제 X) |
| 신규 꾸미기(MVP) | 칭호 + 라커룸 배경까지만 |
| 닉네임 | 리그 첫 참여 시 요청(온보딩 강제 X) |
| 프로필 | 라커룸 통합·2겹(비참여=꾸미기 정체성만, 참여=+리그 정체성) |
| 위치 | 오늘경기 탭 "오늘의 예측" 카드 |
| 마감 리마인드 | 마감 30분 전 푸시(미예측자·1일1회 이하) — MVP 포함, 인프라 문제 시 비차단 |

## 2. MVP 범위

- 하루 1회 예측 + **첫 경기 시작 전 마감**(변경·신규 불가).
- 서버 판정(`actualTopGameId` / `tiedGameIds`) + 유저·날짜당 중복 방지 + 상태(`pending|hit|miss|void`).
- 포인트: 참여 소량 + 적중 + 연속 보너스.
- **랭킹: 월간 포인트(메인) + 월간 적중률(보조, 최소 참여).**
- **오늘 결과 확인 + 연속 적중 기록**(일간은 랭킹이 아님).
- 보상 3층(참여·적중 / 월간 / 시즌).
- **신규 꾸미기: 칭호 + 라커룸 배경.**
- 닉네임(리그 참여 시) + 프로필(라커룸 통합) + 공개 프로필.
- **판정 이유 UX**(왜 이 경기가 실제 꿀잼이었나).
- **예측 마감 30분 전 리마인드**(푸시, 미예측자만, 1일 1회 이하).
- 진입: 오늘경기 탭 "오늘의 예측" 카드.

---

## 3. 후속 범위 (Phase 5+)

- 팬덤 대항전 · 시즌 패스(무료 미션부터) · 크라우드 꿀잼 노출 · 친구 랭킹.
- **프로필 프레임 · 예측 카드 꾸미기**(꾸미기 확장).
- 연속 적중 **별도 랭킹**(MVP는 내 기록/칭호 조건).
- **주간 랭킹**(MVP는 주간=미션 또는 최근 7일 폼 표시용).
- 광고 보상 · IAP(Phase 6).

## 4. 금지 / 가드레일 (무결성)

**야구공으로 절대 불가:**
- 랭킹 포인트 구매 · 추가 예측권 · 예측 수정권 · 힌트 · 보상 배율 증가.

**시스템 불변:**
- 결과 판정 변경 불가 · 공식 꿀잼지수는 유저 예측/야구공에 의해 바뀌지 않음.
- `actualTopGameId`/`tiedGameIds` 판정은 **서버 실데이터로만** 산출.
- 운영자 수동 보정이 필요하면 **로그와 사유를 남긴다**.

**야구공 사용처 = 꾸미기 / 표현 / 수집만:**
- 허용(MVP): 스킨 · 라커룸 배경 · 일반 칭호.
- 허용(후속): 프로필 프레임 · 예측 카드 꾸미기.

**표현:** "베팅/배당/판돈/수익률" 금지. "예측 참여/적중 보상/랭킹 포인트" 사용.

## 5. 데이터 구조 초안

```ts
// 서버 판정 결과(하루 1건). Phase 3-Pre 파이프라인 산출.
DailyHoneyResult {
  date: string;                 // YYYYMMDD (KST)
  actualTopGameId?: string;     // 실제 꿀잼 1위(단독 시)
  tiedGameIds?: string[];       // 동률 시 공동 1위들(둘 중 하나 예측=적중)
  recapScore: number;
  liveHeatPeak?: number;
  decidingReasonTags: string[]; // 판정 이유 UX용 (예: "9회 동점","끝내기","heat 98")
  calculatedAt: string;
}

// 유저 1일 1예측.
UserPrediction {
  id: string; userId: string; date: string;
  selectedGameId: string; selectedAt: string; lockedAt?: string;
  status: 'pending' | 'hit' | 'miss' | 'void';
  rewardBaseballs: number; rankingPoints: number;
}

// 유저 집계(랭킹·프로필).
UserPredictionStats {
  userId: string; nickname?: string;
  totalPredictions: number; totalHits: number; hitRate: number;
  currentStreak: number; bestStreak: number;
  monthlyPoints: number; seasonPoints: number;
  equippedTitle?: string; /* 장착 칭호·배경 등 꾸미기 참조 */
}
```

- **칭호 · 라커룸 배경** = 스킨의 "보유→장착" 구조 확장(신규 테이블 필요): `owned_titles`/`owned_backgrounds` + `profiles.equipped_title`/`equipped_background`(비민감, RLS 직접) 형태 검토.
- **닉네임** 저장 위치·스키마, 공개 프로필 매핑은 구현 단계 확정(§10).

## 6. UX 진입 위치 · 흐름

- **오늘경기 탭 상단 "오늘의 예측" 카드**(경기 목록 위). opt-in.
- **예측 전:** 오늘 경기 중 1개 선택(첫 경기 시작 전까지). 첫 참여면 닉네임 설정.
- **예측 후:** 잠금 + "내 예측: {팀 vs 팀} · 결과 대기중".
- **결과:** 판정 후 **"오늘의 실제 꿀잼 경기 + 선정 이유"** + 적중/미적중 + 보상 표시.
  - 예: `LG 5:4 한화 — 9회 동점 · 끝내기 · live.heat 98 · recapScore 91`
- **프로필/랭킹:** 라커룸 통합 진입 + 월간 리더보드.

**프로필(라커룸 통합, 2겹):**
- 비참여자: "🎯 예측 리그 참여하기" CTA + 꾸미기 정체성(적용 스킨·배경·야구공·출석·응원팀).
- 참여자: + 닉네임 · 장착 칭호 · 적중률 · 연속 · 이번달 순위.
- **공개 프로필**(리더보드에서 남이 탭): 참여자만. §9의 공개 허용 항목만.

## 7. 보상 / 랭킹 정책

**포인트 (v1 예시 — 수치는 구현 단계 확정):**
- 참여 +1 · 적중 +10 · 연속 적중 보너스 +2 · void = 점수 변화 없음(연속 유지).
- 참여 포인트는 소량 → "매일 찍기만" 노가다 방지. 적중·연속이 핵심.

**랭킹:**
- **메인 = 월간 포인트 랭킹.**
- 보조 = 월간 적중률 랭킹. **최소 참여 조건**: MVP 월 5회+ / 정식 월 10회+ / (시즌 적중률은 30회+ 검토).
- 연속 적중 = 별도 랭킹 아님 → 내 기록 · 프로필 요약 · 업적/칭호 조건.

**신규 유저 공정성:**
- 통산 누적 랭킹을 **메인으로 두지 않는다.** 메인 = **월간(리셋)** → 늦게 시작해도 다음 달 새로 경쟁.
- 시즌 랭킹 = 장기 명예/기록. 통산 = 내 프로필/명예의 전당 성격만.

**보상 3층:**

| 층 | 대상 | 보상 |
|---|---|---|
| 참여·적중 | 전원 | 참여 소량 포인트 / 적중 시 야구공 + 랭킹 포인트 / 연속 보너스 |
| 월간 | 월간 상위권 + 참여·달성 | 월 한정 배지 + 소량 야구공 (상위권만이 아니라 달성 보상도) |
| 시즌 | 시즌 최상위권 | **한정 칭호 · 전용 스킨 · 라커룸 배경** |

- 시즌 보상 = **야구공으로 구매 불가(프레스티지)** + **다음 시즌 경쟁 우위를 주지 않음**.
- **소장 가치 4요소:** ① 희소성(시즌 한정·상위 N명) ② 과시성(리더보드·프로필 노출) ③ 미감(에셋 퀄리티) ④ 서사("2026 예측왕"). ①+②가 엔진.

## 8. 엣지케이스 처리

- **예측한 경기가 시작 전 취소** → 재선택 기회 제공. 재선택 안 하면 **void**.
- **void는 miss가 아니다** → 연속 적중 기록을 끊지 않는다.
- **전 경기 취소 / 노게임 / 서스펜디드 / 데이터 장애** → 불이익 없이 처리, 판정 대상 제외.
- **동률** → `tiedGameIds` 허용. 그중 하나를 예측했으면 적중. 결과 화면 "공동 꿀잼 경기" 표시.
- **마감 후** 신규 예측·변경 불가.

---

## 9. 닉네임 / 공개 프로필 / 프라이버시

**닉네임:**
- 리그 첫 참여 시 요청(온보딩 강제 X). **공개 랭킹에 표시됨을 안내.**
- 중복 방지. 부적절 닉네임은 **운영자가 숨김/변경**(운영 원칙). 변경은 MVP 후순위 또는 월 1회 제한.

**공개 프로필 표시 가능:** 닉네임 · 칭호 · 이번달 포인트 · 적중률 · 연속 적중 · 장착 배경/프레임.

**공개 금지(절대):** 이메일 · 로그인 제공자 · 야구공 잔액 · 거래내역 · 내부 `user_id`.

## 10. 구현 전 미결정 (후속 검토)

- **괴리율**(경기 전 꿀잼지수 예측 vs 실제 꿀잼 1위 불일치율) 실데이터 — 리그 성립의 핵심 근거. **2026 시즌 데이터 충분히 쌓인 뒤** recap-history로 산출·판단.
- **찐팬 페르소나 니즈 검증** (`/persuasion-review`) — 원할 때.
- 포인트 정확 수치 · 최소 참여 임계값 최종값.
- 칭호 · 라커룸 배경 **구체 목록 / 에셋**(에셋 퀄리티 = 소장 가치 결정).
- 라커룸 프로필 통합 방식 · 리더보드 화면 상세.
- 닉네임 저장 스키마 · 공개 프로필 화면 · 부적절 닉네임 운영 도구.
- **선행 구현: Phase 3-Pre 판정 파이프라인**(`DailyHoneyResult` 산출 + tie-breaker A→B→C→D + 동률 tiedGameIds).
