# PRD — 오늘야구각 (DugoutPick)

## 한 줄 정의
KBO 경기를 **꿀잼지수(0~100)**로 점수화해 "오늘 뭐 볼지" 골라주는 iOS/Android 앱.

## 목표 / 맥락
- 빠른 MVP 출시 → 시장 반응으로 가설 검증 → 다음 Y Combinator batch 합격.
- **북극성 원칙: 속도 최우선, 동시에 안정적.** 이 트레이드오프가 모든 결정의 기준 — 망설일 땐 "더 빨리 출시 + 깨져도 안 죽는 쪽"을 택한다.

## 타깃 유저
1차 = **이미 야구를 보는 코어 팬.** (꿀잼지수의 가중치·문구가 이 기준에 맞춰져 있음. 캐주얼 유입은 후순위 가설.)

## 핵심 가치 = 꿀잼지수
경기마다 0~100 점수 + **한 줄 이유** + 관전포인트 3개. 규칙 기반(AI 아님 — 의도는 adr.md ADR-004/005). 공식·필드는 data-schema.md / honjam-formula 메모리.

## 기능 범위 (MVP)
| 기능 | 내용 |
|---|---|
| 온보딩(필수) | 응원팀 선택(팀명+대표색상 그리드), 로컬 저장. 최초 1회 |
| 오늘경기 탭 | 추천 히어로(최고 꿀잼) 최상단 + 나머지 경기(꿀잼 높은 순, 시간·구장·꿀잼지수) |
| 경기 상세 | 꿀잼지수 / 한 줄 예측(reason) / 관전포인트(points) / 선발 매치업(이름·ERA) |
| 내 팀 탭 | 피드형 스크롤(다음경기·순위·최근결과) |
| 설정 탭 | 최소: 응원팀 변경 · 데이터 갱신시각 · 앱 정보 |

## 비범위 (Out of Scope — 의도적으로 안 만든다)
로그인/회원 · 운영 서버(백엔드 API) · 푸시 알림 · 유료화 · 실시간 중계.
→ 모두 "속도·단순·서버없음" 원칙에 따라 MVP에서 제외. (배경: adr.md ADR-002)

## 완료 기준
1. 핵심 흐름 정상 작동: 실행→로고→팀선택→오늘경기→추천 최상단→경기 상세 (flow.md)
2. 온보딩 팀선택 / 추천경기 표시 / 경기 상세 / 내 팀 탭 각각 작동
3. 도트 UI가 전 화면에 적용
