# PRD — 오늘야구각 (DugoutPick)

## 한 줄 정의
KBO 경기를 **꿀잼지수(0~100)**로 점수화해 "오늘 뭐 볼지" 골라주는 iOS/Android 앱.

## 목표 / 맥락
- 빠른 MVP 출시 → 시장 반응으로 가설 검증 → 다음 Y Combinator batch 합격.
- **북극성 원칙: 속도 최우선, 동시에 안정적.** 이 트레이드오프가 모든 결정의 기준 — 망설일 땐 "더 빨리 출시 + 깨져도 안 죽는 쪽"을 택한다.

## 타깃 유저
1차 = **이미 야구를 보는 코어 팬.** (꿀잼지수의 가중치·문구가 이 기준에 맞춰져 있음. 캐주얼 유입은 후순위 가설.)

## 핵심 가치 = 꿀잼지수
경기마다 0~100 점수 + **한 줄 이유** + 관전포인트 3개. 규칙 기반(AI 아님 — 의도는 adr.md ADR-004/005). 공식·필드는 data-schema.md / honjam-formula 메모리.

## 기능 범위 (MVP + 출시 후 확장)
| 기능 | 내용 |
|---|---|
| 온보딩(필수) | 응원팀 선택(팀명+대표색상 그리드), 로컬 저장. 최초 1회 |
| 오늘경기 탭 | 추천 히어로(최고 꿀잼) + **지금 볼 각(LIVE 경기 실시간 점수·이닝·`heat`)** + 나머지 경기(꿀잼 높은 순) |
| 경기 상세 | 꿀잼지수 / 한 줄 예측 / 관전포인트 / 선발 매치업(이름·ERA·승패) / 라인업 / (FINAL)결산·승패투수 |
| 내 팀 탭 | 피드형 스크롤(다음경기·순위·최근결과 + 월요일엔 월요 리포트) |
| 순위 화면 | 10팀 순위표 전체(MyTeam에서 진입) |
| 설정 탭 | 응원팀 변경 · **꿀잼지수 스킨 선택** · 데이터 갱신시각 · 앱 정보 |
| 꿀잼지수 스킨 | 배지 스킨 4종(유니폼 클래식/핀스트라이프/크림 + 레트로 전광판). 탭=즉시 적용 (ADR-019) |
| 트랙레코드 | 꿀잼지수 누적 적중률 배지(경기 전 freeze 예측 기준, 정직성 게이트) (ADR-017) |
| 경기 후 피드백 | FINAL 경기에서 👍/👎 + 이유 태그 → AsyncStorage 저장 + Discord 웹훅(무음 실패) |

**라이브 점수**는 ADR-002의 "서버 없음"을 깨지 않는 선에서, Cloudflare Worker 엣지 함수가 요청 시점에 KBO 실시간 데이터를 오버레이해 제공한다(ADR-018).

## 비범위 (Out of Scope — 의도적으로 안 만든다)
로그인/회원 · 운영 서버(백엔드 API) · 푸시 알림 · 유료화 · 실시간 중계 영상.
→ "속도·단순·서버없음" 원칙에 따라 제외. 단, **라이브 점수**는 무서버 엣지 함수(Worker)로 제공(ADR-018). (배경: adr.md ADR-002)

## 완료 기준
1. 핵심 흐름 정상 작동: 실행→로고→팀선택→오늘경기→추천 최상단→경기 상세 (flow.md)
2. 온보딩 팀선택 / 추천경기·라이브 표시 / 경기 상세 / 내 팀 탭 / 순위 / 스킨 선택 각각 작동
3. 도트 UI가 전 화면에 적용
