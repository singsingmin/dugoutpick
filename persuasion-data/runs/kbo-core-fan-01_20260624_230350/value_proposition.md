## 랜딩 카피

### 헤드라인

**"오늘 5경기 중 뭐가 꿀잼인지, 1초 만에."**

### 서브헤드

KBO 경기를 꿀잼지수(0~100)로 점수화해 "오늘 뭐 볼지"를 알려주는 앱.
로그인 없음. 서버 없음. 광고 없음.

### 핵심 문구 3줄

- 퇴근 후 한 경기밖에 못 볼 때 — 놓치면 아까운 경기를 미리 골라드립니다.
- 에이스 등판, 연패 탈출 발판, 와일드카드 판가름 — 지수를 올리는 이유를 한 줄로 설명합니다.
- 꿀잼지수가 실제 명경기와 얼마나 맞았는지, 누적 적중률로 직접 확인하세요.

## 미팅/미디어용 상세 설명

### 1. 핵심 기능

#### 꿀잼지수 (0~100)

오늘 예정된 KBO 경기를 6가지 요소로 수치화합니다:
- 팀 순위 근접도 (박빙 순위 경쟁)
- 에이스/선발 투수 퀄리티
- 팀 간 최근 맞대결 히스토리
- 홈/원정 분위기 및 팀 현재 모멘텀
- 리그 순위 중요도 (와일드카드·포스트시즌 레이스)
- 연승·연패 강도 (기세 절정 / 탈출 발판)

→ 6요소 가중합 + 로지스틱 보정 → 0~100 정수 출력.

#### 한 줄 이유 — 상황별 5+ 패턴 (최근 업데이트)

"왜 이 점수인지"가 항상 함께 표시됩니다. 단순 문구가 아닌 경기 상황에 맞는 구체적 문구:

- **에이스 등판**: "김광현 ERA 2.3 압도적 에이스 등판"
- **연패 탈출**: "한화 4연패 탈출 발판"
- **와일드카드**: "5위·6위 와일드카드 판가름"
- **장기 연승**: "KT 6연승 질주, 기세 절정"
- **동반 슬럼프**: "양 팀 동반 슬럼프, 승기 선점 싸움"
- **화력 최고조**: "양 팀 최근 10경기 합 16승, 화력 최고조"

#### 누적 적중률 트랙레코드

DugoutPick이 경기 전에 예측한 꿀잼지수가 실제 경기 결과와 얼마나 일치했는지 누적 통계를 앱 내에서 공개합니다.
- **hitRate**: "예측 적중" 비율 (경기 재미가 예상 범위 내)
- **bonusRate**: "기대 이상" 비율 (예상보다 훨씬 재밌었음)
- 최근 50경기 슬라이딩 윈도우 — 가장 최근 예측 성능 반영
- 최소 10경기 이상 누적돼야 수치 공개 (표본 확보 전 "집계 중")

→ "이 앱이 잘 맞는지"를 앱이 스스로 증명합니다.

#### 경기 후 피드백 기능 (개발 예정)

경기 종료 후 "실제로 재밌었나요? 👍👎" 한 번의 탭으로 평가.
- 쌓인 평가가 꿀잼지수 정확도 튜닝에 반영됩니다.
- Discord 채널로 즉시 전송 — 앱이 "사용자 평가로 스스로 개선"하는 구조.

#### 내 팀 탭

선택한 팀(예: 한화)의 경기를 피드 형식으로 모아봅니다.
내 팀 경기가 없는 날에도 다른 경기 중 꿀잼지수 상위 경기를 추천합니다.

#### 경기 상세

- 꿀잼지수 + 한 줄 이유 (상황별 구체 문구)
- 선발 투수 (양팀, ERA 포함 — 규정 미달 선발도 표시)
- 관전 포인트 3개
- 팀 간 최근 맞대결 기록

### 3. 신뢰도 장치

**DugoutPick이 "정확도로 승부"하는 앱임을 증명하는 구조:**

1. **예측 고정(frozen) 원칙**: 꿀잼지수는 경기 시작 전에 확정, 이후 수정 불가. 소급 조작 없음.
2. **트랙레코드 누적 공개**: 예측 vs 실제 결과를 앱에서 직접 확인 가능.
3. **규칙 기반 투명성**: AI 블랙박스가 아닌, 명시된 6가지 요소의 가중합. 이유가 항상 함께 표시.
4. **사용자 피드백 루프**: 경기 후 👍👎 평가 → 가중치 튜닝 반영 예정. "쓸수록 더 맞아지는" 구조.

### 4. 설치·사용

- **무료 앱 (Google Play Store)**
- 설치 → 응원 팀 선택 → 끝. 로그인 없음.
- 경기 데이터 자동 갱신 (GitHub Actions 파이프라인, 약 5분 주기). 오프라인도 캐시로 동작.
- 가볍고 빠름: 서버 없는 정적 데이터 구조.
