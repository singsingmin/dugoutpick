## 랜딩 카피

### 헤드라인

**"오늘 5경기 중 뭐가 꿀잼인지, 1초 만에."**

### 서브헤드

KBO 경기를 꿀잼지수(0~100)로 점수화해 "오늘 뭐 볼지"를 알려주는 앱.  
로그인 없음. 서버 없음. 광고 없음.

### 핵심 문구 3줄

- 퇴근 후 한 경기밖에 못 볼 때 — 놓치면 아까운 경기를 미리 골라드립니다.
- "박빙 승부, 에이스 선발, 탑팀 맞대결" — 지수를 올리는 이유를 한 줄로 설명합니다.
- 꿀잼지수가 실제 명경기와 얼마나 맞았는지, 누적 적중률로 직접 확인하세요.

## 미팅/미디어용 상세 설명

### 1. 핵심 기능

#### 꿀잼지수 (0~100)

오늘 예정된 KBO 경기를 6가지 요소로 수치화합니다:
- 팀 순위 근접도 (박빙 순위 경쟁)
- 에이스/선발 투수 퀄리티
- 팀 간 최근 맞대결 히스토리
- 홈/원정 분위기
- 팀별 현재 연승·연패 모멘텀
- 리그 순위 중요도 (와일드카드·포스트시즌 레이스)

→ 6요소를 가중 합산 후 로지스틱 보정 → 0~100 정수 출력.  
→ **"왜 이 점수인지" 한 줄 이유가 항상 함께 표시됩니다.** (예: "선두권 박빙 + 류현진 선발")

#### 누적 적중률 트랙레코드 (신규)

DugoutPick이 경기 전에 예측한 꿀잼지수가 실제 경기 결과와 얼마나 일치했는지 누적 통계를 앱 내에서 공개합니다.
- **hitRate**: "예측 적중"(경기 재미가 예상 범위 내) 비율
- **bonusRate**: "기대 이상"(예상보다 훨씬 재밌었음) 비율
- 최소 10경기 이상 누적돼야 수치 공개 (충분한 표본 확보 전 "집계 중" 표시)
- 최근 50경기 슬라이딩 윈도우 — 가장 최근 예측 성능을 반영

→ "이 앱이 잘 맞는지"를 앱이 스스로 증명합니다.

#### 내 팀 탭

선택한 팀(예: 한화)의 경기를 피드 형식으로 모아봅니다.  
내 팀 경기가 없는 날에도 다른 경기 중 꿀잼지수 상위 경기를 추천합니다.

#### 경기 상세

- 꿀잼지수 + 한 줄 이유
- 선발 투수 (양팀)
- 관전 포인트 3개
- 팀 간 최근 맞대결 기록

### 2. 왜 기존 대안과 다른가

| 구분 | 네이버 스포츠 / KBO 앱 | 야구 커뮤니티 | **DugoutPick** |
|---|---|---|---|
| "오늘 뭐 볼지" 추천 | ✗ | ✗ (주관적 여론) | **✓ (객관 지수)** |
| 추천 이유 설명 | ✗ | 부분적 | **✓ (한 줄 이유)** |
| 예측 성능 공개 | N/A | N/A | **✓ (트랙레코드)** |
| 로그인 | 필요 | 필요 | **불필요** |
| 광고 | 있음 | 있음 | **없음** |

---

### 3. 신뢰도 장치

**DugoutPick이 "정확도로 승부"하는 앱임을 증명하는 구조:**

1. **예측 고정(frozen) 원칙**: 꿀잼지수는 경기 시작 전에 확정되고 이후 수정되지 않습니다. 경기 결과를 보고 소급해 점수를 바꾸지 않습니다.
2. **트랙레코드 누적 공개**: 예측 vs 실제 결과를 앱에서 직접 확인 가능.
3. **규칙 기반 투명성**: AI 블랙박스가 아닌, 명시된 6가지 요소의 가중합. "왜 이 점수인지"가 항상 함께 표시됩니다.

### 4. 설치·사용

- **무료 앱 (Google Play Store)**
- 설치 → 응원 팀 선택 → 끝. 로그인 없음.
- 경기 데이터는 자동 갱신 (Actions 파이프라인, 약 5분 주기). 오프라인도 캐시로 동작.
- 가볍고 빠름: 서버 없는 정적 데이터 구조.
