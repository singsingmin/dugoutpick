## 랜딩 카피

### 헤드라인

**"오늘 5경기 중 뭐가 꿀잼인지, 1초 만에."**

### 서브헤드

KBO 경기를 꿀잼지수(0~100)로 점수화해 "오늘 뭐 볼지"를 알려주는 앱.
로그인 없음. 서버 없음. 광고 없음.

### 핵심 문구 3줄

- 퇴근 후 한 경기밖에 못 볼 때 — 놓치면 아까운 경기를 미리 골라드립니다.
- 에이스 등판, 연패 탈출, 와일드카드 판가름 — 지수를 올리는 이유를 한 줄로 설명합니다.
- 경기 중이라면 실시간 점수까지. 앱 켜두면 60초마다 자동 갱신.

## 미팅/미디어용 상세 설명

### 1. 핵심 기능

#### 꿀잼지수 (0~100)

오늘 예정된 KBO 경기를 6가지 요소로 수치화합니다:
- 팀 순위 근접도 (박빙 순위 경쟁)
- 에이스/선발 투수 퀄리티 (ERA 포함)
- 팀 간 최근 맞대결 히스토리
- 홈/원정 분위기 및 팀 현재 모멘텀
- 리그 순위 중요도 (와일드카드·포스트시즌 레이스)
- 연승·연패 강도 (기세 절정 / 탈출 발판)

→ 6요소 가중합 + 로지스틱 보정 → 0~100 정수 출력. 공식은 공개됨(AI 블랙박스 없음).

#### 한 줄 이유 — 상황별 구체 문구

"왜 이 점수인지"가 항상 함께 표시됩니다:

- **에이스 등판**: "김광현 ERA 2.3 압도적 에이스 등판"
- **연패 탈출**: "한화 4연패 탈출 발판"
- **와일드카드**: "5위·6위 와일드카드 판가름"
- **장기 연승**: "KT 6연승 질주, 기세 절정"
- **동반 슬럼프**: "양 팀 동반 슬럼프, 승기 선점 싸움"
- **화력 최고조**: "양 팀 최근 10경기 합 16승, 화력 최고조"

#### 라이브 실시간 폴링 (신규)

LIVE 경기 진행 중에는 앱이 **60초마다 자동으로 점수를 갱신**합니다.
- 스코어, 이닝, 팀 상황이 실시간으로 업데이트
- LIVE 경기가 없는 시간대에는 폴링 중단 → 배터리 낭비 없음
- 앱을 켜두기만 하면 됨. 새로고침 버튼 누를 필요 없음

#### 라인업 조회 (신규)

경기 상세에서 **오늘 양 팀 선발 라인업(타순 1~9번·포지션·선수명)**을 확인할 수 있습니다.
- KBO 공식 API 기반 실시간 데이터
- 발표 전이라면 "최근 기준 추정 타순"으로 표시 (추정임을 명시)
- 선발 투수 섹션 옆 버튼 한 번 → 바텀시트로 바로 확인

#### 누적 적중률 트랙레코드

DugoutPick이 경기 전에 예측한 꿀잼지수가 실제 경기 결과와 얼마나 일치했는지 누적 통계를 앱 내에서 공개합니다.
- **hitRate**: "예측 적중" 비율
  - **적중 판정 기준**: 꿀잼지수 70 이상 예측 경기 중 실제 경기가 연장전·끝내기·3점 이내 접전 중 하나라도 해당하면 적중
  - 기준이 명시되어 있어 "운영자 재량"으로 바꿀 수 없음
- **bonusRate**: "기대 이상" 비율 (예상보다 훨씬 재밌었음)
- 최근 50경기 슬라이딩 윈도우 — 가장 최근 예측 성능 반영
- 최소 20경기 이상 누적돼야 수치 공개 (표본 부족 시 "집계 중")

→ "이 앱이 잘 맞는지"를 앱이 스스로 증명합니다.

#### 내 팀 탭

선택한 팀(예: 한화)의 경기를 피드 형식으로 모아봅니다.
내 팀 경기가 없는 날에도 다른 경기 중 꿀잼지수 상위 경기를 추천합니다.

#### 경기 상세

- 꿀잼지수 + 한 줄 이유 (상황별 구체 문구)
- 선발 투수 (양팀, ERA 포함 — 규정 미달 선발도 개별 조회로 표시)
- 관전 포인트 3개
- 팀 간 최근 맞대결 기록
- 선발 라인업 (바텀시트, 발표 전 추정 표시)

### 3. 신뢰도 장치

**DugoutPick이 "정확도로 승부"하는 앱임을 증명하는 구조:**

1. **예측 고정(frozen) 원칙**: 꿀잼지수는 경기 시작 전에 확정, 이후 수정 불가. 소급 조작 없음.
2. **트랙레코드 + 판정 기준 공개**: 적중 판정이 어떻게 이루어지는지 앱에 명시. "운영자 재량"이 끼어들 수 없는 구조.
3. **규칙 기반 투명성**: AI 블랙박스가 아닌, 명시된 6가지 요소의 가중합. 이유가 항상 함께 표시.
4. **데이터 갱신 SLA**: GitHub Actions 파이프라인으로 5분 주기 자동 갱신. 선발 투수 변경은 KBO 공지 후 약 10분 이내 반영(파이프라인 주기 기반).

### 4. 설치·사용

- **무료 앱 (Google Play Store / 사이드로드 APK)**
- 설치 → 응원 팀 선택 → 끝. 로그인 없음.
- 경기 데이터 자동 갱신 (약 5분 주기). 오프라인도 캐시로 동작.
- LIVE 경기 중에는 60초 자동 갱신으로 점수 실시간 추적 가능.
