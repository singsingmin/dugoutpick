# 오늘야구각 (DugoutPick) — 가치제안

> 전달 모드: `landing_plus_meeting` (랜딩 카피 + 세일즈/제품 설명)
> 대상: 이미 야구를 보는 KBO 코어 팬

---

## PART 1. 랜딩페이지 카피

### 헤드라인
**오늘 5경기, 뭐 볼지 1초 만에.**
KBO 전 경기를 **꿀잼지수(0~100)**로 점수 매겨 "오늘 이거 봐" 한 경기를 골라줍니다.

### 서브 카피
일정·순위는 네이버에도 있습니다. 우리가 주는 건 **"오늘 이 경기가 왜 볼 만한가"** 입니다.
경기마다 꿀잼지수 + **한 줄 이유** + **관전포인트 3개**. 감으로 고르거나 커뮤니티 여론 뒤지지 않아도 됩니다.

### 핵심 3줄
- ⚾ **꿀잼지수** — 순위 싸움·최근 폼·맞대결·선발 매치업 등을 규칙으로 합산한 0~100 점수. AI 환각 없음, 계산식이 일관됩니다.
- 💬 **한 줄 이유 + 관전포인트** — "왜 재밌는지"를 사람이 읽는 문장으로. "공동 5위 마지노선 한 판" 같은 맥락까지.
- 📱 **로그인·서버 없음** — 깔고 응원팀만 고르면 끝. 데이터 파이프라인이 깨져도 마지막 캐시를 보여주고 앱은 안 죽습니다.

### CTA
**무료. 광고 없음. 응원팀 고르고 바로 오늘 경기 보기.**

---

## PART 2. 세일즈 미팅 / 제품 상세

### 우리가 푸는 문제
코어 팬은 매일 5경기를 다 못 봅니다. 퇴근 후 하나만 고를 때, 네이버 스포츠는 일정·순위는 주지만 **"오늘 이 경기가 왜 볼 만한지"는 안 알려줍니다.** 그래서 감으로 고르거나 엠팍 여론에 의존하고, 다음 날 다른 경기의 끝내기·역전 하이라이트를 보고 "이걸 놓쳤네" 후회합니다. 우리는 그 **관전 의사결정 비용을 0에 가깝게** 만듭니다.

### 작동 방식
1. **온보딩(최초 1회)** — 응원팀 선택(팀명+대표색 그리드), 로컬 저장. 회원가입 없음.
2. **오늘경기 탭** — 최고 꿀잼 경기를 히어로로 최상단에, 나머지는 꿀잼 높은 순으로(시간·구장·지수).
3. **경기 상세** — 꿀잼지수 / 한 줄 예측 / 관전포인트 3개 / 선발 매치업(이름·ERA·승패). 종료 경기는 승·패 투수까지 표시.
4. **내 팀 탭** — 다음 경기·순위·최근 결과를 피드형으로.
5. **설정** — 응원팀 변경 · 데이터 갱신시각 · 앱 정보.

### 꿀잼지수가 믿을 만한 이유
- **규칙 기반 6요소 가중합 + 로지스틱 보정.** 블랙박스 AI가 아니라 일관된 공식이라, 같은 상황이면 같은 점수가 나옵니다.
- 순위 임팩트(공동순위 마지노선 등), 최근 폼(무승부 반영), 맞대결, 선발 매치업, 박빙 기대치 등을 반영.
- 한 줄 이유는 규칙 기반 문구라 **틀린 헛소리를 지어내지 않습니다.**

### 데이터 신뢰성
- KBO 공식 데이터를 정적 JSON 파이프라인으로 수집(GitHub Actions, 5분 주기 외부 cron 트리거).
- 선발 ERA는 규정 미달 투수도 개별 조회로 커버. 종료 경기 승/패 투수 표시.
- 서버 장애에 의존하지 않음 — 마지막으로 받은 데이터를 보여주고 앱이 죽지 않는 구조.

### 가격
**완전 무료. 구독·광고 없음.** (수익화 이전 MVP 단계 — 지금은 "오늘 뭐 볼지"를 잘 맞히는 것에만 집중.)

### 지금 한계 (솔직하게)
- 꿀잼지수의 실경기 적중률은 아직 누적·튜닝 중입니다. 초기엔 체감과 어긋나는 경기가 있을 수 있고, recap 데이터로 가중치를 계속 보정합니다.
- 푸시 알림·실시간 인앱 티커는 아직 없습니다(탭 재진입 시 갱신). 로컬 알림은 로드맵에 있습니다.
- iOS는 아직, 현재 Android(APK) 중심.

### 왜 지금, 왜 이거
경쟁자(네이버·KBO 공식앱·커뮤니티)는 데이터·여론은 주지만 **"한 경기를 골라주는" 큐레이션이 없습니다.** 우리는 그 한 가지를 빠르고 가볍게, 서버 없이 합니다. 전환 비용도 낮습니다 — 깔고 팀만 고르면 오늘 당장 씁니다.
